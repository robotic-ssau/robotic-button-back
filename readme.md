
## Бэк для управления состоянием лаборатории клуба Robotic
Данный код предназначен для взаимодействия с telegram-ботом и физической кнопкой для контроля состояния открытия лабы. Для сборки и запуска проекта используются следующие команды:
```sh
docker build -t fastapi-app .
docker run -d -p 8000:80 fastapi-app
```
